## Соответствие основным требованиям

| Требование | Где реализовано и как проверено |
|---|---|
| База в 3НФ, первичные и внешние ключи | `database/01_schema.sql`, `ChudoObuv_3NF.xlsx`, `NORMALIZATION.md`; 10 отношений, ограничения проверены на MSSQL |
| ER-диаграмма PDF и SQL с данными | `ER_diagram.pdf`, `database/database_with_data.sql` |
| Каталог с изображением, категорией, производством, составом и ценой | `MainView.xaml`, `ProductView.xaml`, `Store.GetProducts`; загрузка и рендер WPF проверены |
| Наличие много/мало, выделение остатка не более трёх пар и заглушка | `Models.cs`, `MainView.xaml`, `Ui.Image`; расчёт суммарного остатка по размерам |
| Скидка 25% за отсутствие заказов в предыдущем календарном месяце | `Pricing` и запросы `Store`; проверены границы месяца и года, високосная дата и округление копеек |
| Вход только по логину, ФИО и роли | `Store.Login`, `MainWindow.SetUser`; проверены логины, неизвестный логин и проверки роли в БД |
| Совместные поиск по названию/описанию, категория и сортировка | `MainWindow.ApplyFilters`; проверены немедленное обновление и сохранение сортировки |
| Карточка модели, размер, количество, корзина и подтверждение | `MainWindow`, `ProductView.xaml`, `CartView.xaml`; проверены события WPF, количества и транзакционное оформление |
| Менеджер и администратор работают со списком и составом заказов | `OrdersView.xaml`, `Store.GetOrders/GetOrderLines`; менеджер видит заказы, административные элементы скрыты |
| Администратор меняет дату и удаляет позиции | `ChangeOrderDate`, `DeleteOrderLine`; проверены права, пересчёт суммы, возврат количества и запрет пустого заказа |
| Защита от нехватки товара, устаревшей цены и одновременной покупки | Транзакции `SERIALIZABLE`, блокировки и повторная проверка цены; соответствующие тесты прошли |
| Единый стиль, заголовки, логотип, иконка и Calibri | Встроенные XAML и `Ui`; прежние пользовательские изменения интерфейса сохранены |
| Оформление кода, одна команда в строке | C# отформатирован Roslyn; последовательности токенов приложения до/после совпадают |
| Исходники в структуре папок, EXE, SQL и README в репозитории | `src/ChudoObuv`, `ChudoObuv.exe`, `database`, `README.md`; автоматические скрипты сохранены |

Файл конфигурации `.dt` относится к варианту реализации на платформе 1С. Для согласованного стека C#, WPF и MSSQL результат базы предоставлен SQL-скриптами с данными.

## Что добавлено по результатам проверки

1. Руководство пользователя в Word и PDF: 14 страниц, семь иллюстраций, структура предоставленного шаблона, назначение, подготовка, вход, общие приёмы, четыре роли, подробные операции и устранение ошибок.
2. Исходные иллюстрации в `docs/screenshots`, полученные из настоящих WPF-форм на учебных данных отдельной MSSQL.
3. Дополнительная проверка интерфейса менеджера и снимки входа и поиска в существующих интеграционных тестах.
4. Форматирование C# без изменения токенов приложения, пересборка EXE и исправление устаревшего упоминания 11 листов Excel в документации. В текущей книге ровно 10 листов; её данные и оформление не изменялись.

Проверки выполнены на базе `ChudoObuv_ArchiveTest20261016`; все 15 групп успешны. Пользовательские заказы основной базы не использовались для испытаний. Подробности и команды повторения находятся в `TESTING.md`.
