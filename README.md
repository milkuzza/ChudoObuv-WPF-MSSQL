# Чудо Обувь

Готовое настольное приложение по заданиям 1–4 КИМ 09.02.07-2-2027. Стек: **C#, WPF, Microsoft SQL Server, ADO.NET**, .NET Framework 4.8. Пять исходных Excel-файлов преобразованы в 10 связанных таблиц третьей нормальной формы.

## Запуск

На Windows x64 с .NET Framework 4.8 и SQL Server Express LocalDB запустите **Launch.cmd**. Скрипт создаст базу `ChudoObuv`, импортирует исходные данные и откроет приложение. При повторном запуске уже подготовленная база сохраняется.

Полная инструкция с установкой компонентов, подключением к SQL Server Express/Developer, сборкой и устранением ошибок: [START.md](START.md).

Ручное создание базы, импорт собственного нормализованного Excel и перенос кода в новый проект Visual Studio: [MANUAL_SETUP.md](MANUAL_SETUP.md).

## Возможности

- Каталог с исходными изображениями, заглушкой, категорией, наименованием, производством, составом и ценой.
- Скидка 25% для модели без заказов в предыдущем календарном месяце. Расчёт в копейках с округлением до целой копейки.
- Наличие «много» при количестве больше 5, иначе «мало». При суммарном количестве не более 3 фон карточки `#ff8080`.
- Вход по логину, ФИО в правом верхнем углу, разные права для покупателя, менеджера и администратора.
- Поиск по названию и описанию, фильтр по категории и сортировка цены в обе стороны. Все параметры применяются совместно при изменении.
- Карточка модели, актуальный размерный ряд, доступные размеры, выбор количества, корзина из нескольких позиций.
- Изменение количества и удаление позиций корзины, подтверждение и отмена заказа.
- Менеджер и администратор просматривают состав всех заказов, оформляют заказ на выбранного клиента и удаляют заказы.
- Администратор меняет дату заказа и удаляет отдельные позиции. Последнюю позицию удаляют вместе с заказом.
- Оформление заказа, возврат остатков при удалении и удаление позиции выполняются транзакционно. Права проверяются в слое работы с данными.

Интерфейс использует Calibri, белый фон, `#D2F6E7`, акцент `#70B2AF`, исходные логотип и иконку. XAML встроен в сборку и загружается через стандартный `XamlReader`; C# связывает события и данные. NuGet-пакеты для работы приложения не нужны.

Контроль импорта: **31 модель, 92 сочетания модели и размера, 1 274 доступные пары, 10 заказов, 30 строк заказов, 36 заказанных пар, 341 770,00 ₽**. Исторические заказы повторно не вычитались из предоставленного снимка доступных остатков.

Excel служит подготовленным набором данных. Работа приложения изменяет базу MSSQL; автоматической синхронизации с Excel нет. Внешние ключи в Excel обозначены идентификаторами, а их целостность обеспечивает MSSQL.

Для открытия в Visual Studio скачайте или клонируйте весь репозиторий и откройте `ChudoObuv.sln`. Перед первым запуском подготовьте базу через `Launch.cmd` либо по ручной инструкции. Сборка решения создаёт EXE в `src/ChudoObuv/bin/Release` или `bin/Debug`; сам сервер MSSQL и его база устанавливаются отдельно.
