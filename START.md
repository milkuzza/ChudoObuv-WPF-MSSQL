# Инструкция по запуску «Чудо Обувь»

Пошаговая работа в приложении со снимками интерфейса описана в [руководстве пользователя PDF](docs/USER_GUIDE.pdf) и [редактируемой версии Word](docs/USER_GUIDE.docx). Эта инструкция посвящена установке компонентов, подготовке базы и сборке.

## 1. Необходимые компоненты

Приложение предназначено для Windows x64. Для запуска нужны:

1. **.NET Framework 4.8 Runtime**. На большинстве актуальных Windows он уже установлен. При необходимости установите его с [сайта Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48).
2. **Microsoft SQL Server**. Для простого локального запуска используйте SQL Server 2022 Express LocalDB. На [официальной странице SQL Server 2022 Express](https://www.microsoft.com/en-us/download/details.aspx?id=104781) скачайте установщик, выберите Download Media → LocalDB и установите полученный `SqlLocalDB.msi`. LocalDB — компонент SQL Server Express; подробнее в [документации Microsoft](https://learn.microsoft.com/en-us/sql/database-engine/configure-windows/sql-server-express-localdb).

Visual Studio, Excel, Python и подключение к интернету после установки компонентов для запуска EXE не требуются. Устанавливать SQL Server Management Studio необязательно.

## 2. Самый быстрый запуск

1. Полностью распакуйте архив в обычную папку, например `C:\Projects\ChudoObuv`. Не запускайте EXE из окна просмотра архива.
2. Оставьте рядом с `ChudoObuv.exe` файл `ChudoObuv.exe.config`, каталог `Assets`, скрипты и каталог `database`.
3. Дважды щёлкните **Launch.cmd**. PowerShell подготовит базу на `(LocalDB)\MSSQLLocalDB`, импортирует данные и запустит приложение.
4. Каталог сразу доступен гостю. Нажмите «Войти по логину» и введите один из логинов ниже.

| Роль | Логин |
|---|---|
| Администратор | `isivanov` |
| Менеджер | `papetrov` |
| Покупатель | `asidorova` |

Пароль не вводится. При успешном входе ФИО появится в правом верхнем углу.

База создаётся один раз. Повторный запуск не восстанавливает и не стирает заказы. Для следующих запусков можно открывать `ChudoObuv.exe` напрямую.

## 3. Подготовка базы вручную

Откройте PowerShell в папке решения:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Initialize-Database.ps1
.\ChudoObuv.exe
```

Если LocalDB не запущен или экземпляр не создан:

```powershell
& 'C:\Program Files\Microsoft SQL Server\160\Tools\Binn\SqlLocalDB.exe' info
& 'C:\Program Files\Microsoft SQL Server\160\Tools\Binn\SqlLocalDB.exe' create MSSQLLocalDB
& 'C:\Program Files\Microsoft SQL Server\160\Tools\Binn\SqlLocalDB.exe' start MSSQLLocalDB
```

Команду `create` выполняйте только если `info` не показывает `MSSQLLocalDB`. Номер каталога `160` относится к SQL Server 2022; у другой установленной версии путь может отличаться.

Альтернатива через SSMS: подключитесь к `(LocalDB)\MSSQLLocalDB` с Windows Authentication, откройте `database\database_with_data.sql` и выполните весь файл. Скрипт создаёт базу `ChudoObuv` и импортирует данные. Если в этой базе уже есть таблицы, импорт останавливается. Для проверки после импорта выполните:

```sql
USE ChudoObuv;
SELECT COUNT(*) AS model_count FROM dbo.products;           -- 31
SELECT COUNT(*) AS variant_count FROM dbo.stock_items;      -- 92
SELECT SUM(available_quantity) AS pairs FROM dbo.stock_items; -- 1274
SELECT COUNT(*) AS order_count FROM dbo.orders;             -- 10
SELECT SUM(total_kopecks)/100.0 AS rubles FROM dbo.order_totals; -- 341770.00
```

## 4. Подключение к SQL Server Express или Developer

Например, для установленного экземпляра `localhost\SQLEXPRESS`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Initialize-Database.ps1 -Server 'localhost\SQLEXPRESS' -Database 'ChudoObuv'
```

В файле `ChudoObuv.exe.config` замените значение `connectionString`:

```xml
Data Source=localhost\SQLEXPRESS;Initial Catalog=ChudoObuv;Integrated Security=True;Connect Timeout=15;Application Name=ChudoObuv
```

Затем запустите EXE напрямую. `Launch.cmd` по умолчанию готовит именно LocalDB. Чтобы использовать его с другим сервером, задайте переменную окружения для текущего PowerShell:

```powershell
$env:CHUDOOBUV_CONNECTION_STRING = 'Data Source=localhost\SQLEXPRESS;Initial Catalog=ChudoObuv;Integrated Security=True;Connect Timeout=15'
.\Launch.cmd
```

Эта переменная имеет приоритет над конфигурацией и используется и приложением, и скриптом импорта. Учётной записи Windows необходимы доступ к серверу и право создания базы при первом импорте. Для существующей подготовленной базы достаточно прав чтения и изменения её таблиц.

Если имя `ChudoObuv` уже занято другой базой, выберите новое:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Initialize-Database.ps1 -Database 'ChudoObuvDemo'
```

Укажите то же имя в `Initial Catalog` конфигурации. Скрипты не удаляют чужие или существующие таблицы. Для нового чистого набора данных создайте базу с новым именем.

## 5. Оформление заказа

1. Войдите по логину. Введите часть названия или описания в поиск, выберите категорию и порядок цены. Результат меняется сразу, параметры работают совместно.
2. Нажмите на карточку модели. Ознакомьтесь с описанием и составом, выберите доступный размер и количество.
3. Нажмите «Добавить в корзину». Повторите для других моделей или размеров.
4. Откройте корзину. Выберите строку для изменения количества или удаления позиции. Менеджер и администратор также могут выбрать клиента.
5. Нажмите «Подтвердить заказ» и подтвердите сумму. Дата сохранится автоматически, остатки уменьшатся.
6. «Продолжить выбор» сохраняет текущую корзину. «Отменить заказ» очищает её после подтверждения.

При нехватке товара или изменении цены заказ целиком отклоняется. Уменьшите количество; при изменении цены закройте и снова откройте корзину. После успешного оформления каталог обновляется.

## 6. Работа с заказами

Для менеджера и администратора доступна кнопка «Заказы»:

- Верхний список показывает номер, дату, ФИО клиента и итог. При выборе заказа ниже отображаются модель, производство, размер, количество и историческая цена каждой позиции.
- «Добавить заказ» возвращает в каталог: выберите позиции и оформите корзину на нужного клиента.
- «Удалить заказ» после подтверждения удаляет заказ целиком и возвращает количество всех позиций в доступные остатки.
- Администратор дополнительно может выбрать дату и нажать «Сохранить дату», а также удалить выделенную позицию заказа. Удаление единственной позиции запрещено: для этого удалите заказ целиком.

После каждого изменения список заказов, его состав, итог и остатки обновляются. Изменение даты может повлиять на текущую скидку модели, но не меняет цену уже оформленного заказа.

## 7. Открытие и сборка исходников

В Visual Studio установите компонент «Разработка классических приложений .NET» и .NET Framework 4.8 Targeting Pack. Откройте `ChudoObuv.sln`, выберите Release / Any CPU и выполните Build. Исполняемый файл появится в `src\ChudoObuv\bin\Release`; рядом будут конфигурация и `Assets`. Базу подготовьте скриптом из корня решения.

Сборка без Visual Studio через встроенный компилятор .NET Framework:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Готовый `ChudoObuv.exe` и его конфигурация появятся в корне решения. Установка NuGet-пакетов не нужна. Интерфейс хранится в `src\ChudoObuv\Views\*.xaml`, запросы и транзакции — в `Store.cs`, события окон — в `MainWindow.cs`.

## 8. Проверки

Инструкция по запуску автоматических проверок находится в `docs\TESTING.md`. Используйте отдельную базу с `Verification` или `Test` в имени, поскольку проверки временно меняют данные.

## 9. Если не запускается

| Сообщение или ситуация | Действие |
|---|---|
| Ошибка подключения к MSSQL | Проверьте установленный LocalDB, имя экземпляра и строку подключения. Выполните раздел 3. |
| `Cannot open database` | Подготовьте базу через `Initialize-Database.ps1`; проверьте `Initial Catalog`. |
| `Login failed` | Используйте ту учётную запись Windows, от которой подготовлена база; проверьте права на обычном SQL Server. |
| База уже содержит таблицы | Укажите новое имя базы и такое же имя в конфигурации. Скрипт сохраняет существующие данные. |
| PowerShell блокирует выполнение | Запускайте приведённую команду с `-ExecutionPolicy Bypass`; глобальные настройки менять не нужно. |
| Логин не найден | Скопируйте логин из таблицы выше или из листа `users`. Используются латинские символы. |
| Товаров нет после поиска | Очистите строку поиска и выберите «Все категории». |
| В каталоге скидка на все модели | Это ожидаемо, если в предыдущем календарном месяце не было заказов. Исходные заказы датированы апрелем и маем 2026 года. |

При переносе на другой компьютер переносите всю папку решения и заново создайте базу из SQL. Рабочая база хранится SQL Server на том компьютере, где она была создана. Excel и SQL-файлы остаются эталоном первоначального импорта.
